# Security policy

This repository is a course project built on synthetic data. If you find a vulnerability in the code or configuration, please open a private security advisory on GitHub (Security > Advisories > Report a vulnerability) rather than a public issue.
Include what you found, how to reproduce it, and what you think the impact is. You will get an acknowledgement within 3 business days.

Never include real patient data in a report. If you believe real PHI has been committed here, tell us immediately through the same channel so it can be removed from history.

Proposed handling targets for a production deployment: critical vulnerabilities patched within 7 days, high within 30, with the hospital notified according to the incident response plan (`docs/compliance/incident-response-plan.md`).
